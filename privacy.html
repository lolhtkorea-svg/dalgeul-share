개인정보처리방침

적용일: 2026년 11월 26일

달결에 입력한 출생 정보로 운세를 계산하는 과정은 기기 안에서 이루어집니다. 광고, 지도, 공유 등 외부 서비스를 이용할 때의 정보 처리는 아래에서 따로 안내합니다.

1. 운세 입력과 기기에 저장되는 정보

생년월일, 양력·음력·윤달 여부, 출생 시각, 성별과 커플운세에 입력한 MBTI는 운세 계산에 사용합니다. 달결은 이 입력값을 자체 서버나 광고 서비스에 보내지 않습니다. 달결의 별도 회원 계정은 없습니다.

  • 내 정보 기억하기: 선택하면 내 출생 정보와 성별을 이 기기에 저장합니다. 커플운세에서 선택하면 내 MBTI도 함께 저장합니다. 상대방의 입력 정보는 저장하지 않습니다.
  • 화면과 알림 설정: 선택한 테마, 권한 안내 여부, 운세 알림의 켜짐·꺼짐, 다음 예약 시각과 최근 처리 상태를 기기에 보관합니다. 알림을 중복해서 보내지 않고 설정 상태를 보여주기 위한 정보입니다.
  • 공유 이미지: 공유하기를 선택할 때 결과 이미지가 기기의 앱 임시 저장공간에 만들어질 수 있습니다.

2. 선택 권한과 위치 이용

위치는 현재 위치와 가까운 데이트 장소를 정렬하거나 지도에서 길을 찾는 데 사용합니다. 위치 권한을 거절해도 운세를 볼 수 있으며, 지역을 직접 고를 수 있습니다. 달결은 백그라운드 위치 권한을 요청하지 않고, 위치 이동 이력을 저장하지 않습니다.

현재 위치는 이용 중 필요한 동안 메모리에서만 사용합니다. 빠른 장소 표시를 위해 조회한 공개 장소의 주소·좌표를 기기에 임시 보관할 수 있으며, 이 장소 정보에는 사용자의 현재 위치나 출생 정보가 들어가지 않습니다.

지도·길찾기를 선택하면 선택한 목적지와 검색어가 해당 지도 서비스에 전달됩니다. 주소를 좌표로 바꾸는 과정에는 휴대폰의 위치·지도 서비스가 이용될 수 있습니다. 외부 서비스에서의 위치 처리는 해당 서비스의 설정과 방침에 따릅니다.

알림 권한은 오늘·주간 운세를 알리는 데 사용합니다. 정시 알림 권한은 예약한 시각에 알림을 요청하기 위한 선택 권한입니다. 두 권한 모두 휴대폰의 달결 앱 설정에서 바꿀 수 있습니다.

3. 광고와 개인정보 선택

달결은 Google의 광고 서비스를 사용할 수 있습니다. 광고 서비스는 광고 제공, 이용 분석과 부정 사용 방지를 위해 IP 주소, 앱 실행·광고 터치 등 이용 정보, 오류·성능 정보, 광고 ID와 기기 관련 식별자를 처리할 수 있습니다. IP 주소로 대략적인 지역을 추정할 수 있습니다. 운세에 입력한 생년월일·출생 시각·성별·MBTI를 광고 서비스에 별도로 전달하지 않습니다.

지역과 적용되는 선택 사항에 따라 Google의 개인정보 선택 안내가 표시됩니다. 필요한 선택을 확인한 뒤 광고 요청 가능 상태에 따라 광고를 불러옵니다. 선택을 바꿀 수 있는 경우 앱에 광고 개인정보 설정이 표시됩니다. 광고를 불러오지 못해도 운세 기능을 이용할 수 있습니다.

Google의 정보 처리, 보관과 삭제에 관한 자세한 내용은 Google 개인정보처리방침에서 확인할 수 있습니다. 광고 ID는 휴대폰의 광고 개인정보 설정에서 재설정하거나 삭제할 수 있으며, 메뉴 이름은 Android 버전과 제조사에 따라 다를 수 있습니다.

4. 공유 링크와 외부 서비스

결과를 공유하면 선택한 결과 문구, 이미지와 링크가 사용자가 고른 앱과 받는 사람에게 전달됩니다. 공유 결과에는 원래 입력한 생년월일, 출생 시각, MBTI나 현재 위치를 넣지 않습니다. 공유 링크를 가진 사람은 해당 결과를 볼 수 있으므로 공유할 대상을 확인해 주세요.

공유 결과 웹페이지는 GitHub Pages에서 제공합니다. 페이지 접속 시 호스팅 제공자가 IP 주소와 브라우저 등 접속 정보를 처리할 수 있습니다. 달결이 공유 페이지에 별도의 회원 계정이나 자체 방문 분석 도구를 운영하지는 않습니다. 자세한 내용은 GitHub 개인정보처리방침을 참고해 주세요.

카카오톡 카드 공유에서 공유 카드 준비하기를 누르면 결과 요약 이미지를 카카오 서버에 올립니다. 이어서 카카오톡으로 보내기에서 직접 대상을 고르면 결과 이미지·요약·링크가 전달됩니다. 원래의 출생 정보나 현재 위치는 이 이미지에 넣지 않습니다. 카카오의 이미지 업로드 안내에 따르면 업로드한 이미지는 최대 100일 동안 보관된 뒤 자동 삭제됩니다. 이미 받은 사람이 보관한 메시지나 사본의 삭제를 뜻하지는 않습니다.

카카오의 정보 처리는 카카오 개인정보처리방침에 따릅니다. 외부 지도, 문자, 이메일 앱을 이용할 때도 각 서비스의 방침과 사용자가 선택한 전송 내용이 적용됩니다.

전문가 상담 문의 버튼은 문자 작성 화면을 엽니다. 사용자가 직접 문자를 보내면 전화번호와 작성한 내용이 해당 상담사에게 전달됩니다. 달결은 연락처 목록이나 문자 내역을 읽지 않고, 문자를 자동 전송하지 않습니다.

5. 보관과 삭제

기기에 기억한 내 정보는 해당 화면에서 내 정보 기억하기를 해제하면 지워집니다. 개인 운세와 커플운세의 기억하기 설정은 각각 해제할 수 있습니다. 알림은 앱의 운세 알림 설정에서 끌 수 있습니다.

기기에 남은 입력 정보, 테마·알림 설정, 광고 선택 기록과 임시 파일을 함께 지우려면 휴대폰 설정에서 달결의 앱 데이터를 삭제하거나 앱을 삭제할 수 있습니다. 데이터를 삭제하면 기존 설정도 초기화됩니다. 다른 사람에게 이미 전달한 메시지·이미지·링크는 앱 데이터를 지워도 회수되지 않습니다.

외부 서비스가 처리한 정보의 보관·삭제와 선택 철회는 각 서비스에서 안내하는 방법을 이용해 주세요. 달결 운영자에게 개인정보에 관한 문의나 요청을 하려면 아래 이메일로 연락할 수 있습니다.
